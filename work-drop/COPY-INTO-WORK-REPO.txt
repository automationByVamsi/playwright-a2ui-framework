  report.passed is false on exactly the runs compareFactFind throws on. NOT ASSESSABLE
  findings are reported but never fail a run: they are the rows one side is silent about.

  Compares fact_find only (not summaryBox / analysis). Per customer: name, DOB, age,
  marital, address, related/unrelated accounts, status/opened/role/parties,
  support needs, related parties, contact notes. Both files must quote the same
  complaintRef, and a customer's accordion being absent is reported separately from
  it saying "none recorded".

  To add a field later: add one row to factfind-map.ts (source paths, UI locator, match type).
  json-get.ts reads the locators, compare-map.ts matches them. No other file changes.
  To see what a row resolves to before you add it, use the POC's review dashboard
